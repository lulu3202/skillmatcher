# Architecture diagrams

## Canonical artifact

[container.html](container.html) is the only canonical architecture diagram for the approved behavior-first review. Its source is [container.json](container.json), and it matches [docs/03-architecture.md](../../docs/03-architecture.md).

## Historical artifacts

All other diagrams in this directory predate the approved behavior-first methodology. They are historical review experiments and are **non-authoritative**. In particular, do not use them to infer a curated/product-owned catalog, fixed scoring rules, caching, a selected stack, an API, persistent storage, or unapproved components.

Use the canonical interaction contracts, payload contracts, runtime sequence, and architecture document for current review.
